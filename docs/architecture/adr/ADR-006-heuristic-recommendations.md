# ADR-006: موتور توصیه‌گر اکتشافی (Heuristic Recommendation Engine)

## وضعیت
تصویب‌شده (Accepted) — آبان ۱۴۰۵ / اکتبر 2026 — موج W17+

## زمینه
دامنه `ai-recommendation` در نقشه دامنه سند مادر (P2) است. راه‌حل‌های ML خارجی (بردار‌سازی، مدل‌های colaborative) هزینه زیرساخت و داده آموزش می‌خواهند که در فاز فعلی توجیه ندارد؛ اما «محصولات مرتبط»، «پرفروش‌ها» و «شخصی‌سازی» تاثیر مستقیم بر نرخ تبدیل دارند.

## تصمیم
موتور توصیه اکتشافی (Heuristic) سه‌کاناله سمت سرور، بدون هیچ وابستگی خارجی:
1. **مرتبط‌ترین‌ها (Related):** محصولات هم‌دسته با کالای جاری، مرتب‌شده بر اساس مجموع تعداد فروش واقعی (تجمیع `order_lines`).
2. **پرفروش‌ترین‌ها (Popular):** رتبه‌بندی سراسری بر اساس مجموع فروش — منبع حقیقت: دیتابیس سفارشات.
3. **برای شما (For-You):** بر اساس رویدادهای `product_viewed`/`add_to_cart` جدول `analytics_events` برای `sessionId` کاربر → استخراج دسته‌های موردعلاقه → برترین کالاهای همان دسته‌ها.

قواعد غیرقابل مذاکره: خروجی همیشه از API سرور می‌آید (هرگز کلاینت رتبه‌بندی نمی‌کند)، حالت DB-down با منطق دمو تاب‌آور پاسخ می‌دهد، و قرارداد پاسخ شامل `source` (DB | FALLBACK) است تا قابل ممیزی بماند.

## پیامدها
- ارتقای آینده به مدل协同 collaborative صرفاً با تعویض پیاده‌سازی سرویس است؛ قرارداد API ثابت می‌ماند.
- هیچ داده PII در توصیه‌ها استفاده نمی‌شود (فقط sessionId ناشناس).
