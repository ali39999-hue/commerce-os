# Multi-Agent Operating Model
1. Orchestrator: scope، dependency، assignment، conflict resolution.
2. Repository Auditor: route/API/component/permission discovery.
3. UX Researcher: user tasks و usability.
4. Design System Architect: tokens و component contracts.
5. Figma Designer: frames، variants و responsive layouts.
6. Frontend Implementer: کدنویسی در scope مصوب.
7. Backend Integrator: فقط تغییر API/data با approval.
8. Accessibility Reviewer: keyboard، contrast و semantics.
9. Visual QA: screenshot diff و responsive.
10. Security Reviewer: auth، permissions و data exposure.
11. Release Reviewer: evidence و rollback.

هر فایل در هر task فقط یک owner داشته باشد. Design approval قبل از implementation گسترده الزامی است. هیچ Agent حق merge/deploy خودکار ندارد.
