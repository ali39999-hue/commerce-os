# Brand & UX Direction
## ترکیب سه کانسپت
- Editorial Botanical: فضای تنفس، عکس طبیعی، Serif editorial و حس انسانی.
- Precision Clinical: نظم، شواهد علمی، جزئیات دقیق و ساختار خوانا.
- Modern Apothecary: متریال سنگی/کاغذی، بسته‌بندی مینیمال و رنگ خاکی.

## قواعد
- زمینه‌های Ivory/Cream؛ Forest و Sage برای برند؛ Champagne فقط accent.
- یک CTA اصلی در هر ناحیه.
- عکس واقعی محصول/دستگاه بر تصویر تولیدی اولویت دارد.
- تصویر AI فقط برای concept؛ نه ادعای محصول واقعی.
- متن علمی بدون ادعای درمانی تأییدنشده.
- فروشگاه گرم و editorial؛ ERP دقیق، کاربردی و با density کنترل‌شده.
- RTL با CSS logical properties پیاده شود.
