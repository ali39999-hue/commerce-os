# Responsive & RTL
از breakpointهای موجود پروژه استفاده شود. در نبود قرارداد: compact <640px، medium 640–1023px، large 1024–1439px، wide ≥1440px.
- Mobile طراحی task-first باشد، نه صرفاً desktop کوچک.
- ERP table در موبایل از row detail یا horizontal scroll کنترل‌شده استفاده کند.
- CTA موبایل قابل دسترسی و غیرمزاحم باشد.
- از margin-inline/padding-inline/inset-inline/text-align:start استفاده شود.
- آیکون جهت‌دار در RTL در صورت نیاز mirror؛ آیکون برند/علمی mirror نشود.
- تاریخ/ارز/عدد از formatter مرکزی پروژه استفاده کند.
- متن بلند فارسی و انگلیسی تست شود.
