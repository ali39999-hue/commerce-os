# Accessibility & Content
هدف WCAG 2.2 AA، با ابزار خودکار و بررسی انسانی.
- contrast، focus واضح، keyboard navigation، labels/errors، alt، target size، reduced motion.
- dialog focus trap و restore focus.
- status announcement برای screen reader.
- محتوای علمی دارای author/reviewer/date/references/version باشد.
- ادعای پزشکی/درمانی بدون evidence و approval منتشر نشود.
- قیمت، rating، stock و review فقط از داده واقعی.
