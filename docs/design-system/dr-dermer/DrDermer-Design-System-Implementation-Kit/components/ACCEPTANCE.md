# Component Acceptance
- قبل از ساخت جزء جدید، معادل موجود بررسی شود.
- variantها بر اساس intent نام‌گذاری شوند.
- tokenها جایگزین رنگ/spacing hardcode شوند.
- کنترل تعاملی keyboard و focus واضح داشته باشد.
- input دارای label، hint و error باشد.
- dialog/drawer focus management داشته باشد.
- DataTable loading/empty/error/sort/pagination را پشتیبانی کند.
- ERP permission UI جایگزین backend authorization نیست.
- تست و Story نمونه برای اجزای اصلی اضافه شود.
