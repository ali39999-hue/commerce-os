# Dr Dermer — Design System Implementation Kit
نسخه 1.0 — Blueprint اجرایی، نه تغییر انجام‌شده روی Repository.

هویت نهایی: **Warm Editorial Clinical Luxury**؛ ترکیب Editorial Botanical، Precision Clinical و Modern Apothecary.

## منابع حقیقت
1. Repository: مرجع کد، API، route و business logic.
2. این بسته: مشخصات طراحی و قواعد پیاده‌سازی.
3. Figma: مرجع طرح‌های تأییدشده.
4. Storybook/Component Catalog: مرجع اجزای پیاده‌سازی‌شده.

## شروع
1. در Git یک branch مجزا بسازید.
2. این بسته را در `docs/design-system/dr-dermer/` قرار دهید.
3. ابتدا Repository Audit و baseline را اجرا کنید.
4. توکن‌ها را با stack واقعی تطبیق دهید.
5. Pilot را روی Header + Hero + Product Card اجرا کنید.
6. پس از تأیید انسانی، توسعه صفحه‌به‌صفحه را آغاز کنید.

هیچ API، route، مجوز یا منطق تجاری صرفاً برای تطبیق ظاهری حذف یا بازنویسی نشود.
