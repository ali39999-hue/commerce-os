## 🌟 معرفی پروژه و هویت بالینی

این پروژه بازآفرینی عمیق و ۱:۱ پایگاه دانش و ویترین رسمی **لابراتوارهای پژوهشی درماتولوژی دکتر درمر انگلستان (Dr. Dermer UK Clinical Laboratories - Cambridge Science Park)** بر بستر هسته مالی و مقیاس‌پذیر **Commerce OS** است.

این سامانه، تجارت الکترونیک محصولات درمانی را با **ایستگاه‌های سخت‌افزاری ۳۶۰ درجه تعاملی، شبیه‌سازهای فیزیولوژیک اثر بوهر (Bohr Effect)، آنالیز ترکیبات دارویی و اینچی (INCI)، تست‌های مقایسه‌ای VISIA، و پروتکل‌های ترمیم سد دفاعی پوست** ترکیب نموده است؛ در حالی که در لایه تراکنش، حسابداری دوبل مالی بدون ممیز شناور (`BigInt`)، رزرو اتمیک انبار، پشتیبانی کامل از زنجیره سرد (۲ تا ۸ درجه) و صدور فاکتور رسمی مالیاتی سامانه مودیان (ماده ۱۶۹ مکرر) را تضمین می‌کند.

## 🏛️ معماری مونوریپو و سیستم طراحی Anti-Slop

معماری پروژه مبتنی بر **Turborepo 2.11 + pnpm 12** و طراحی ۱۰۰٪ منطبق بر پروتکل **Anti-Slop (R-01 to R-40)** است:
- **`apps/storefront`**: فریم‌ورک Next.js 16.4.3 (Turbopack، App Router، React 19) شامل ۴۶ مسیر ایستا و پویا با استایل Obsidian Dark و تایپوگرافی وزیرمتن.
- **`apps/admin`**: پنل عملیات سازمانی ERP با ۱۳ ماژول نظارتی، بررسی فیش‌های بانکی، پایش زنجیره سرد و اکسپورت استاندارد سپیدار.
- **`apps/api`**: هسته NestJS 11 و دیتابیس توزیع‌شده با Prisma ORM 7.10.1 بر پایه PostgreSQL 17.
- **`packages/ui`**: سیستم طراحی مستقل با موتور Vitest و کامپوننت‌های پایه‌ای دکمه، دراور، مدال و اسلایدرهای قبل/بعد.
- **`packages/finance`, `domain`, `localization`, `security`, `gateways`**: بسته‌های مستقل منطق مالی، محاسبات ارزی تومان/ریال، امنیت و درگاه‌های پرداخت.

## 🛡️ کیفیت، دسترسی‌پذیری و آزمون‌های خودکار

1. **تست‌های مرورگر واقعی Playwright**:
   - ۵۷ آزمون فعال در سه فرم‌فکتور دسکتاپ بزرگ (1440x900)، تبلت (768x1024) و موبایل (390x844).
   - اعتبارسنجی عدم وجود اسکرول افقی ناخواسته (`no horizontal overflow`) و عملکرد روان دراور سبد خرید.
2. **استاندارد دسترسی‌پذیری جهانی WCAG 2.2 Level AA**:
   - کنتراست رنگی بالای ۴.۵:۱ برای تمام متون و دکمه‌ها.
   - انطباق نام در دسترس با برچسب‌های متنی (Label in Name) و نقش‌های استاندارد ARIA.
3. **تست‌های واحد و یکپارچه مونوریپو (`turbo run test`)**:
   - قبولی ۱۰۰٪ هر **۹۷ تست خودکار**.
4. **تست صحه‌گذاری سناریوهای کلینیکال (`verify-clinical-store.mjs`)**:
   - قبولی کامل ۱۰ از ۱۰ مرحله شامل محاسبه دقیق مالیات ارزش افزوده ۱۰٪، رزرو بدون بن‌بست انبار و تراز بی‌نقص دفاتر دوبل مالی (`SUM(DEBIT) === SUM(CREDIT)`).

## 🚀 راه‌اندازی و اجرای محلی

```bash
# نصب پکیج‌ها
pnpm install

# اجرای بیلد کامل مونوریپو
pnpm run build

# اجرای سرورهای توسعه
pnpm run dev

# اجرای تست‌های خودکار
pnpm run test

# اجرای تست‌های مرورگر Playwright
pnpm --filter @commerce-os/storefront exec playwright test

# اجرای آزمون صحه‌گذاری سناریوهای کلینیکال
node scripts/verify-clinical-store.mjs
```
